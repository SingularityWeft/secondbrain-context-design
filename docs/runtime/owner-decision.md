# Owner-Entscheidung zum Runtime-Pfad

- Technische Empfehlung: Codex CLI im lokalen macOS-Sandbox-Wrapper
- Status: `unsigned-technical-default`
- Technisch verifizierter Umfang des mitgelieferten Sandbox-Pfads: ausschließlich synthetische lokale Prüf- und Aufbauarbeit
- Private Praxisnutzung über einen selbst gewählten Agenten: keine pauschale Empfehlung; nur nach eigener Anbieter-, Daten- und Scope-Entscheidung des Users
- Owner-Signatur: nicht vorhanden

Der autonome technische Build darf auf diesem restriktiven Default weiterarbeiten. Eine menschliche Signatur, vertrauliche Runtime-Freigabe oder öffentliche Anbieterempfehlung wird dadurch nicht behauptet. Jeder Workspace-Owner muss Runtime-Matrix, Bedienaufwand, Kostenannahmen, Anbietergrenze und bekannte Risiken vor seinem privaten Praxistest selbst bestätigen.
