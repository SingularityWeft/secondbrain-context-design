# Owner-Entscheidung zum Runtime-Pfad

- Technische Empfehlung: Codex CLI im lokalen macOS-Sandbox-Wrapper
- Status: `unsigned-technical-default`
- Zulässiger Umfang: ausschließlich synthetische lokale Prüf- und Aufbauarbeit
- Öffentliche oder vertrauliche Nutzung: blockiert
- Owner-Signatur: nicht vorhanden

Der autonome technische Build darf auf diesem restriktiven Default weiterarbeiten. Eine menschliche Signatur, vertrauliche Nutzung oder öffentliche Empfehlung wird dadurch nicht behauptet. Der Workspace-Owner muss Runtime-Matrix, Bedienaufwand, Kostenannahmen, Isolationsevidenz und bekannte Grenzen vor einer späteren Freigabe selbst bestätigen.
